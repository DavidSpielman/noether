\doxysubsection{Detailed Description}
Concatenates all input tool paths into a single tool path. 

This modifier changes the input tool paths vector (i.\+e., {\ttfamily noether\+::\+Tool\+Paths} with size {\ttfamily n}) into a single tool path (i.\+e., {\ttfamily noether\+::\+Tool\+Paths} with size of 1). It does not modify the structure of the underlying tool path segments.
