\doxysubsection{Detailed Description}
Extracts the submesh with the vertices captured inside an extruded polygon defined by the input boundary points. 

Operations
\begin{DoxyItemize}
\item Fit plane to boundary points
\item Project boundary points onto fitted plane
\item Extrude a prism defined by the projected boundary to the extents of the mesh in the direction of the fitted plane normal
\item Identify the vertices within the extruded prism
\item Cluster the inlier vertices
\item Extract the single cluster of vertices whose centroid is closest to the centroid of the boundary 
\end{DoxyItemize}
