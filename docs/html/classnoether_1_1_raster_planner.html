Detailed Description

A specification of the tool path planner for covering surfaces in repeating, evenly spaced path lines. By default, a raster planner will produce a path with all points having a consistent orientation, lines which all travel in the same direction across the surface, and the traversal between lines will be in a consistent direction and order.
