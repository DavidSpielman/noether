  • A specification of the tool path planner interface for generating paths around the edges of surfaces. Each edge planner will return a list of closed-loop edges. Segments will be in sequential order in the ToolPath. The ToolPaths (closed loops) are ordered by descending length of the closed loops. All loops will start near a specified point, and all loops will process in the same direction
